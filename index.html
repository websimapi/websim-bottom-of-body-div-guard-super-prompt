Bottom-of-Body DIV Guard

Minimal JS that continuously hides or removes any DIV auto-appended as the last element of the body, unless it’s on the allowed list.

  • Targets only the bottom DIV (document.body.lastElementChild).
  • On load: immediately checks and hides/removes unexpected DIVs.
  • Continuous: MutationObserver + 1s interval sweep for resilience.
  • Default action: display:none !important; visibility:hidden !important; pointer-events:none !important.
  • If data-remove="true": remove() instead of hide.
  • Allowed IDs: editor-container, grid-container (editable list in code).
  • Waits for DOMContentLoaded if body isn’t ready; fails silently.
  • Disconnects on pagehide/beforeunload; survives re-appends and iframes.
  • Plain JS; no UI, no logs.
